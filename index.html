EJERCICIO 10 • CASO 3 (L Variable) Página 3 de la Guía

Enunciado: Hallar los valores de "L" para los que la pulsación de la frecuencia de resonancia del circuito de la figura (Rama 1: R₁ = 2 Ω, L variable // Rama 2: R₂ = 5 Ω, -jX_C = -j10 Ω) es ω = 5000 rad/seg.
(Rta. Guía: L₁ = 2,43 mH ; L₂ = 0,066 mH)

// 1. Admitancia de la rama fija RC (Z₂ = 5 - j10 Ω = 11.18 ∠ -63.43° Ω):
Y₂ = 1 / (5 - j10) = (5 + j10) / (5² + 10²) = 0.0894 ∠ 63.43° S (0.040 + j0.080 S)
// 2. Condición de resonancia (Im[Y_T] = B_L + B_C = 0):
B_L = X_L / (R₁² + X_L²) = B_C = 0.080 S
0.080 · (2² + X_L²) = X_L ⇒ 0.08·X_L² - X_L + 0.32 = 0
X_L² - 12.5·X_L + 4 = 0
// 3. Raíces de X_L y valores de inductancia L = X_L / ω:
X_L1 = [12.5 + √(12.5² - 16)] / 2 = 12.171 Ω ⇒ L₁ = 12.171 / 5000 = 2.434 mH
X_L2 = [12.5 - √(12.5² - 16)] / 2 = 0.329 Ω ⇒ L₂ = 0.329 / 5000 = 0.066 mH
EJERCICIOS 11 y 17 • CASO 4 (C Variable) Página 4 de la Guía

Enunciado (Ej. 17 / Ej. 11): La rama 1 tiene Z₁ = 8 + j6 Ω (en Ej. 11 figura 8 + j16 Ω) a ω = 5000 rad/seg. La rama 2 contiene R₂ = 8,34 Ω en serie con capacidad variable C. Encuentre C para resonancia y dibuje el lugar geométrico de Y.
(Rta. Guía: C = 24 µF = 2,4×10⁻⁵ F)

// 1. Admitancia de la Rama 1 (con Z₁ = 8 + j6 Ω = 10 ∠ 36.87° Ω):
Y₁ = 1 / (8 + j6) = (8 - j6) / 100 = 0.10 ∠ -36.87° S (0.080 - j0.060 S)
// 2. Condición de resonancia (B_C = |B_L| = 0.060 S):
X_C / (R₂² + X_C²) = 0.060 ⇒ X_C² - (1 / 0.060)·X_C + 8.34² = 0
X_C² - 16.67·X_C + 69.55 = 0
// 3. Punto de tangencia (Radio del círculo de C = 1/(2·R₂) = 1/(2·8.34) = 0.060 S):
X_C = 16.67 / 2 = 8.333 Ω (Raíz única doble / Semicírculo tangente al eje Real)
C = 1 / (ω · X_C) = 1 / (5000 · 8.333) = 24.0 µF (2.4 × 10⁻⁵ F)
EJERCICIO 15 • CASO 1 (R₁ / R_L Variable) Página 4 de la Guía

Enunciado: Hallar el valor de R_L (R₁) para el que existe resonancia en el circuito de la figura (Rama 1: R_L variable en serie con j10 Ω // Rama 2: R₂ = 4 Ω en serie con -j5 Ω). Trazar el lugar geométrico de Y y explicar los resultados obtenidos.

// 1. Admitancia de la rama fija RC (Z₂ = 4 - j5 Ω = 6.403 ∠ -51.34° Ω):
Y₂ = 1 / (4 - j5) = (4 + j5) / 41 = 0.1562 ∠ 51.34° S (0.0976 + j0.1220 S)
// 2. Susceptancia máxima alcanzable por la rama R_L + j10 Ω (cuando R_L = 0):
|B_L(máx)| = 1 / X_L = 1 / 10 = 0.1000 S
// 3. Ecuación de resonancia B_L = B_C:
10 / (R_L² + 10²) = 5 / 41 = 0.1220 S ⇒ R_L² + 100 = 82 ⇒ R_L² = -18 (Sin solución real)
Explicación física: Como la susceptancia capacitiva fija (B_C = 0.122 S) es mayor que el diámetro vertical del semicírculo inductivo (1/X_L = 0.10 S), aún cortocircuitando R_L = 0 Ω el circuito sigue teniendo corriente total capacitiva y el semicírculo de Y_T nunca corta al eje real.
EJERCICIO 16 • CASO 2 (R_C Variable para φ = 45°) Página 4 de la Guía

Enunciado: Trazar el lugar geométrico de la intensidad de corriente que circula por el circuito (Rama 1: R₁ = 10 Ω pura // Rama 2: R_C variable en serie con -j4 Ω) y hallar el valor de R_C para el que la diferencia de fase entre V e I_T sea 45°.

// 1. Admitancia total del circuito paralelo:
Y₁ = 1 / 10 = 0.10 ∠ 0° S (0.10 + j0.00 S)
Y₂ = 1 / (R_C - j4) = R_C / (R_C² + 16) + j [4 / (R_C² + 16)]
Y_T = [0.10 + R_C / (R_C² + 16)] + j [4 / (R_C² + 16)]
// 2. Condición de desfasaje φ = 45° (tan 45° = 1 ⇒ Re[Y_T] = Im[Y_T]):
0.10 + R_C / (R_C² + 16) = 4 / (R_C² + 16)
0.10·R_C² + R_C + 1.6 = 4 ⇒ 0.10·R_C² + R_C - 2.4 = 0 ⇒ R_C² + 10·R_C - 24 = 0
R_C = [-10 + √(100 + 96)] / 2 = (-10 + 14) / 2 = 2.00 Ω
EJERCICIO 18 • SÍNTESIS DEL LUGAR GEOMÉTRICO Página 5 de la Guía

Enunciado: Determinar el circuito correspondiente al lugar geométrico de intensidad de corriente representado en la figura sabiendo que ω = 2000 rad/seg, V = 250 ∠ 30° V, I₁ = 25 ∠ -15° A y el semicírculo de I_T es tangente al fasor V.
(Rta. Guía: Rama 1: R₁ = 7,07 Ω, L = 3,54 mH ; Rama 2: R₂ = 7,07 Ω, C = Variable)

// 1. Impedancia de la Rama 1 fija (desfasaje entre V e I₁ = 30° - (-15°) = 45° inductivo):
Z₁ = |V| / |I₁| ∠ 45° = (250 / 25) ∠ 45° = 10 ∠ 45° Ω (7.071 + j7.071 Ω)
R₁ = 7.07 Ω ; X_L = 7.071 Ω ⇒ L = 7.071 / 2000 = 3.54 mH
// 2. Rama 2 variable (el semicírculo parte del extremo de I₁ y es tangente a V):
Componente reactiva de I₁ perpendicular a V: |I_1y| = 25 · sen(45°) = 17.68 A
Para que el semicírculo sea tangente al fasor V, su radio debe ser R_circ = |I_1y| = 17.68 A
Diámetro del círculo de C variable: D_I = V / R₂ = 2 · R_circ = 35.355 A
R₂ = 250 / 35.355 = 7.07 Ω en serie con C = Variable (Caso 4)
EJERCICIO 20 • CORRECCIÓN DEL LUGAR GEOMÉTRICO Página 5 de la Guía

Enunciado: En la figura se encuentra el lugar geométrico de la corriente de un circuito paralelo de dos ramas con V = 100 ∠ 0° V e I_C = 20 ∠ 60° A. ¿Qué cambio en la rama RL (con R_L variable) hace que el extremo inferior A del semicírculo se encuentre exactamente sobre el fasor tensión?
(Rta. Guía: X_L = 5,78 Ω)

// 1. Corriente de la rama capacitiva fija:
I₂ = 20 ∠ 60° A (10.00 + j17.32 A)
// 2. El punto A corresponde al extremo del diámetro vertical de la rama R_L variable (cuando R_L = 0 Ω):
En R_L = 0 Ω, la corriente por la rama inductiva es puramente imaginaria: I₁(A) = -j (V / X_L)
// 3. Para que el punto A caiga sobre el fasor V (Im[I_T] = 0):
Im[I₂] - V / X_L = 0 ⇒ 17.32 - 100 / X_L = 0
X_L = 100 / 17.3205 = 5.774 Ω ≈ 5.78 Ω

Síntesis Analítica y Geométrica de los 4 Casos Prácticos (R₁L // R₂C)

CONDICIÓN GENERAL DE RESONANCIA EN PARALELO (Corriente Total I_T en fase con V):
Y_T = Y₁ + Y₂ = [ R₁/(R₁² + X_L²) + R₂/(R₂² + X_C²) ] + j [ X_C/(R₂² + X_C²) - X_L/(R₁² + X_L²) ]
Im(Y_T) = B_T = 0 ⇔ X_L / (R₁² + X_L²) = X_C / (R₂² + X_C²)
Caso Práctico Orientación y Diámetro del Semicírculo (Y) Valor en el Punto de Resonancia (Im[Y_T] = 0) Condición de Existencia de Resonancia
CASO 1:
R₁ Variable
(X_L, R₂, X_C fijos) 		Diámetro sobre el Eje Imaginario (-jB)
Diámetro D_Y = 1 / X_L
Radio R_Y = 1 / (2·X_L) 		R₁ = √[ X_L · (R₂² + X_C²) / X_C - X_L² ]
(A lo sumo 1 raíz positiva) 		1 / X_L ≥ B_C
Es decir: X_L ≤ (R₂² + X_C²) / X_C.
Si 1/X_L < B_C no hay resonancia.
CASO 2:
R₂ Variable
(R₁, X_L, X_C fijos) 		Diámetro sobre el Eje Imaginario (+jB)
Diámetro D_Y = 1 / X_C
Radio R_Y = 1 / (2·X_C) 		R₂ = √[ X_C · (R₁² + X_L²) / X_L - X_C² ]
(A lo sumo 1 raíz positiva) 		1 / X_C ≥ |B_L|
Es decir: X_C ≤ (R₁² + X_L²) / X_L.
Si 1/X_C < |B_L| no hay resonancia.
CASO 3:
L (X_L) Variable
(R₁, R₂, X_C fijos) 		Diámetro sobre el Eje Real (+G)
Diámetro D_Y = 1 / R₁
Radio R_Y = 1 / (2·R₁) 		X_L² - (1/B_C)·X_L + R₁² = 0
X_L(1,2) = [1 ± √(1 - 4·R₁²·B_C²)] / (2·B_C) 		• 1/(2·R₁) > B_C: 2 Resonancias (X_L1, X_L2)
• 1/(2·R₁) = B_C: 1 Resonancia tangente
• 1/(2·R₁) < B_C: 0 Resonancias
CASO 4:
C (X_C) Variable
(R₁, X_L, R₂ fijos) 		Diámetro sobre el Eje Real (+G)
Diámetro D_Y = 1 / R₂
Radio R_Y = 1 / (2·R₂) 		X_C² - (1/|B_L|)·X_C + R₂² = 0
X_C(1,2) = [1 ± √(1 - 4·R₂²·B_L²)] / (2·|B_L|) 		• 1/(2·R₂) > |B_L|: 2 Resonancias (X_C1, X_C2)
• 1/(2·R₂) = |B_L|: 1 Resonancia tangente
• 1/(2·R₂) < |B_L|: 0 Resonancias
